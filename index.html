SAMPLE SQL ANALYSIS
SELECT p.promotions,
  COUNT(s.salesid) AS sales_volume
FROM sales s
JOIN product p ON s.productid = p.productid
GROUP BY p.promotions
ORDER BY sales_volume DESC;

SQL CASE STUDY

Nexus Retail Project

Using PostgreSQL to investigate retail performance and answer business-focused questions.

Project focus

The analysis investigated the factors behind sales performance and operational risk. SQL queries were used to explore promotions, inventory, economic indicators, seasonality and product movement.

Business objective: identify patterns that can support better inventory decisions, promotional planning and product performance management.
  • SQL joins and aggregations
  • Percentile-based analysis
  • Product and inventory performance
  • Business recommendations
RETAIL PERFORMANCE QUERY
SELECT
  product_name,
  SUM(quantity * price) AS revenue
FROM sales
GROUP BY product_name
ORDER BY revenue DESC;
